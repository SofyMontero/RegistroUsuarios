# WebSdk (HID Lite Client)

Copie aquí el archivo **websdk.client.ui.min.js** desde la instalación de
[HID Authentication Device Client (Lite Client)](https://digitalpersona.hidglobal.com/lite-client/).

Rutas habituales en Windows:

```
C:\Program Files\HID Global\Authentication Device Client\websdk.client.ui.min.js
```

Tras copiarlo, reinicie `npm run dev`.

Sin este archivo la app React mostrará: *"Falta WebSdk en public/websdk/"*.
